# Product discovery

## Problem statements (hypotheses)
1. Designers lose time manually reporting hours; managers lack timely project visibility.
2. Work happens in multiple models/apps, not just Revit.
3. Managers cannot easily distinguish actual effort from billed effort and discretionary discounts.
4. Quoting depends on subjective experience and insufficient historic benchmarks.

## Potential personas
- Designer: zero routine interaction; transparent monitoring and corrections/appeals process.
- Project manager: view time, project budgets, cost drivers, scope changes.
- Business owner: portfolio costs, capacity, realization, historical estimates.
- Admin: deployment, user mapping, permissions, organization/project identifiers, retention.

## Possible capabilities — unapproved
Automatic Windows session tracking; Autodesk-specific connectors; per-model/per-project aggregation; cross-app tracking; idle detection; multiple sessions; offline buffering; manager dashboard; actual vs charged time; loaded labor cost; cost-to-complete; variation tracking; similar-project estimates; project complexity metrics; export; subscriptions; role-based access.

## Open decisions
- Is primary job-to-be-done accurate project hours, billing recovery, or quote accuracy?
- Is it appropriate to capture activity across all applications or only supported CAD/BIM tools?
- Which signals establish 'active working time' without invasive surveillance?
- How are model files mapped to commercial projects across multiple disciplines and renames?
- How to allocate time when Revit is open alongside a meeting/PDF/email?
- What constitutes a completed task and how is complexity captured?
- What does a manager need to see live vs historical?
- Who pays and how is licensing activated without employee daily login?
- What is permitted under employment law, customer contracts and Autodesk terms?
- How do actual-hours records currently exist outside this proposed product?

## Conceptual commercial models
Per-seat subscriptions; team tier; admin licenses; enterprise contracts. Previously discussed A$15/A$29 per user/month were illustrative guesses, not validated prices.

## Risks
Monitoring/privacy, false precision, missed time, double-counting, multi-version Autodesk compatibility, cloud costs, data ownership, confidential project metadata, classification errors, estimates based on small/non-comparable samples, proprietary API constraints.
