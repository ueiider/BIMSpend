## Distribution and maintenance gates

- Window source manifest and license exist at R1-08 `docs/open-source/`. Compare all derived file headers and transitive sources to upstream, record the exact file diffs and verify binaries offer recipients access to corresponding MPL-covered source, including modifications. Verify license and notice preservation. Package workflow alone provides no evidence of source-offer compliance. Track upstream changes without changing the source pin silently.
- Miru root LICENSE is MIT, copyright 2023 Saeloun. Preserve copyright and permission notice with copied substantial portions. Review third-party files independently. Checked `Gemfile`, `Gemfile.lock`, `package.json`, `pnpm-lock.yaml` and `mise.toml`; stack includes Rails 8.1, PostgreSQL, Redis, Devise, Pundit, Stripe, Vite and JS dependencies. A wholesale port would add a second runtime and complicate deployment. No Miru code was added by this audit or identified in audited product code.
- Release engineering must inventory actual packaged dependencies and notices, preserve licenses, verify source availability, track vulnerabilities and maintain provenance. Qualified review is needed before commercial distribution. Avoid any licensing inference from brand, mock exports or prototype status.
